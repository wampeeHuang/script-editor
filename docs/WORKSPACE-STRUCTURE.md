设置、默认项目入口和素材路径保持不变；未改前端布局。旧快照里包含过去的硬编码路径，保留它们供审计，不能因此将其视为当前启动入口。历史脚本整理后不保证可在新位置执行；继续有价值的验证只以 tests 和 checks 的命令为准。
