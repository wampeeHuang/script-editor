## 2026-09-18 · 加工阶段、统一主题与后续画布合同

本节覆盖此前编辑页“所有工具同时常显”、首页独立配色与双尺寸预览的描述。顶部是加工阶段，侧栏是随阶段呈现的具体功能。阶段表达工作上下文，不是自动推断的完成状态，不作强制线性门禁；用户可以回到文案修改内容。修改后的声音失效仍由既有内容哈希机制判断，不能因为切换阶段就标记音频已完成。

完整产品规划为四个加工阶段：

| 阶段 | 加工对象 | 功能与产物 | 本轮状态 |
| --- | --- | --- | --- |
| 文案 | 文字与章节结构 | 编辑、章节排序、改稿请求 | 已有能力接入顶部阶段 |
| 声音 | 文案对应的旁白 | 录音、配音、采用音频、试听 | 已有能力接入顶部阶段 |
| 镜头规划 | 文字/声音对应的画面方案 | 横屏页面、镜头提示、画布外标注、手动或 Agent 规划 | 后续功能；本轮不显示空按钮 |
| 交付 | 本次可交付的项目内容 | 核对范围、选择格式、导出 | 接入当前导出面板，不等于完整 MVP 已通过 |

导入是项目资料入口，不单独作为加工阶段；录音和配音是声音阶段内的两条方式；预览是检查工具，不单独作为加工阶段。当前 UI 暂为文案/声音/交付三个按钮：文案显示助手，声音显示录音/配音/预览，交付显示导出/预览。新建、导入、项目、回收站及撤销/重做/版本/设置/帮助保留为公共入口。

项目路由继续以稳定 ID 寻址，使用 `stage=audio|delivery` 与 `panel=` 表达阶段和工具。文案为默认阶段。刷新、深链接和浏览器前后退按路由恢复，不把加工阶段存成第二份项目登记或改名项目目录。正在录音时不能用阶段按钮切换，避免隐藏正在进行的录音。

### 当前主题与布局实现

主题唯一来源为 `tokens/app-theme.css`。现有首页的已确认色板成为应用默认主题；`--app-accent` 为品牌强调色，强/淡/悬停/选中色由它派生。首页 `--home-*` 与编辑器 Vivi 旧色名作为兼容别名引用同一主题，不再分别定义品牌色。状态成功、警告、失败仍是独立语义，不随品牌色混淆。

编辑页布局位于 `tokens/editor-shell.css`，独立引用 8px 基数、外边距、导航尺寸、页眉高度、文稿宽度和检查器宽度变量。采用 rem 参数与响应式断点，不按截图写死绝对坐标；后续只换主题色不需要重写组件样式。应用 SVG 和 favicon 共用形象，favicon 从当前主题解析颜色，修改根主题变量时同步更新。没有新增主题选择器或修改公共 Vivi 库。

本轮统一桌面 32px 外边距、32×32px Logo、8px 圆角、正文 16px/24px、章节标题 18px、常规检查器 384px。正文左侧阅读定位不因录音/配音抽屉切换而重新居中。窄屏侧栏缩为图标，长句自动增高，章节入口可横向滚动。文本聚焦只有自身 1px 边框，无第二圈高亮。当前项目页眉 112px 容纳项目名与阶段按钮，作为可调布局 token，不机械沿用列表页 128px 页眉。

### 横屏画布的后续边界

本轮字幕预览只呈现 16:9 横屏，去掉并排/纵向同时展示的竖屏画布，修复状态标签与通用 `.empty` 样式冲突。它仍是字幕效果检查器，不是已经实现的自由画布或视频合成能力。

后续镜头规划采用“有边界的横屏页面 + 无界标注空间”：页面内部代表进入成片的内容，页面外的笔记、箭头和 Agent 讨论默认不进入交付。每页/镜头有稳定 ID；箭头显式引用 pageId/shotId，不能只凭空间靠近决定归属。一段文案可关联多镜头，一镜头也可关联多个文案句子；不能强行绑定每句话一页。

小白从基础页面结构开始，熟练用户可在页外自由探索。Agent 建议可定位到具体页面/镜头并供用户审阅，不直接覆盖已确认方案；手动与 Agent 使用同一规划数据。暂不开发横竖尺寸转换、内容自动适配、无限画布、箭头关系或镜头生成。
